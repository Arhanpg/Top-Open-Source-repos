## Browse organization folders

Every company has a dedicated directory under [organizations/](organizations/). Open its README to see the account mapping and repository inventory. Repository records live in that company's `repositories/` subdirectory.

## Repository documentation

Each inspected project record captures its canonical repository URL, direct README URL, purpose, documented features, technology stack, relevant lifecycle notes and upstream README evidence. Use the [repository entry schema](docs/REPOSITORY-ENTRY-SCHEMA.md).

## Research integrity

- Company-to-GitHub-account mappings must be verified against company-controlled sources. Similar names alone do not prove ownership.
- Only mark a repository **README reviewed** after opening its upstream README. Never guess features or technologies from the repository name.
- GitHub search is ranked and paginated; a search result page is not a complete organization inventory.
- A company inventory is **complete** only after every public repository page for its verified account has been fetched and the final page confirmed. Keep archived repositories and label them.
- See [inventory process](docs/INVENTORY-PROCESS.md) and [status definitions](docs/RESEARCH-STATUS.md).
