## What the statuses mean

1. **Pagination complete** means the collector reached the final page of the public repository endpoint for that configured GitHub account. It does not mean every company-associated GitHub account has been discovered.
2. **README captured** means a README was downloaded and its source evidence recorded. It does not mean that the README was manually interpreted.
3. **README unavailable** means the account summary recorded no README for the repository (including known zero-byte README cases). This is a distinct terminal state.
4. **Evidence captured** means README, language and manifest collection reached terminal states. It is not a source-code, vulnerability, security, licensing or performance audit.
5. **Pending / error** is the exact combined metric published in the generated account summaries. The underlying per-repository inventory files are needed to distinguish retryable pending records from actual failures.
6. **Manual technical review** is tracked separately through curated project dossiers. The autogenerated account summaries show zero manual review; the curated catalogue separately contains **68 manually interpreted README-based project dossiers** across nine company folders. Do not add those manual dossiers to the 1,688 capture count or confuse them with the automated status field.
