## Important interpretation

1. **Pagination complete** means every page from the GitHub public repository endpoint was fetched for the configured login. It does not prove that all company-associated GitHub organizations have been discovered.
2. **README captured** means a README was downloaded and its source SHA recorded. It does not mean the file has been read and interpreted by a human.
3. **Evidence captured** means README, language-byte statistics and manifest capture reached terminal states. It is still not a source-code or architecture audit.
4. **Pending/error** counts repositories whose README evidence workflow did not reach terminal status at this snapshot. They must be processed in later batches or retried.
5. **README unavailable** is a distinct terminal state; it is not counted as a README capture.
6. The account set includes 29 AWS accounts listed in the official Open Source at AWS directory in addition to the primary `aws` account. The `official-directory-listed` status proves a published relationship, not that Amazon legally owns every account or authored every repository.
