# Research status definitions

- **README reviewed** — README opened and inspected; purpose, features, and technologies summarized with evidence links.
- **Metadata only** — repository metadata recorded, but README not reviewed. No feature or stack claims are made.
- **README unavailable** — repository exists but an accessible README could not be obtained.
- **Mapping unverified** — candidate account is not yet proven to be official or company-associated.
- **No public org found** — no official public GitHub organization/account established after checking company-owned sources.
- **Inventory complete** — all pages of the public repository listing for the verified account have been fetched and the final page confirmed.

Candidate organization handles in initial company pages are unverified research leads, not ownership assertions.
