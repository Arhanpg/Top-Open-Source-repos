# Research status definitions

- Mapping unverified — the GitHub account is a research lead and has not been corroborated by a company-controlled source.
- Metadata only — repository metadata is recorded, but the README and other evidence have not been captured.
- Evidence captured; manual review pending — README excerpt/headings, language-byte statistics and selected manifest paths have been collected. A person still needs to interpret purpose, features, stack, architecture and limitations.
- README unavailable — the repository exists, but GitHub returned no README for the default branch at capture time.
- Evidence capture incomplete — one or more API requests failed and should be retried from the saved account checkpoint.
- README reviewed — a human opened the upstream README and wrote an evidence-backed interpretation of the project's purpose, features and technologies.
- No public org found — no official public GitHub organization/account was established after checking company-controlled sources.
- Inventory complete — every page of the public repository listing for the verified account has been fetched and the final page confirmed.

A successful automated capture does not imply a manual README review, source-code audit, security review, dependency vulnerability scan or performance benchmark. Candidate handles remain research leads rather than ownership assertions.
