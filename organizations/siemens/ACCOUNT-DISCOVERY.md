## Additional product-specific organizations

Siemens's company-controlled [Open Source by Siemens](https://opensource.siemens.com/projects/siemens/) page says the main `siemens` GitHub account is not the only source of Siemens projects and explicitly names `mindsphere` and `industrial-edge` as examples of product-specific organizations.

| GitHub organization | Product/project area | Example public repository confirmed |
|---|---|---|
| [mindsphere](https://github.com/mindsphere) | Siemens MindSphere / industrial IoT ecosystem | [mindsphere/mindconnect-nodejs](https://github.com/mindsphere/mindconnect-nodejs) |

## Attribution and scope

- The two secondary accounts use `official-project-linked`, because the Siemens portal gives them as product-specific project examples rather than claiming that all content in those accounts is centrally owned by Siemens.
- The portal says there may be other product-specific organizations; this register is a confirmed starting set, not a complete Siemens account directory.
- Siemens also uses GitLab for some projects; this GitHub catalogue does not include GitLab repositories.
