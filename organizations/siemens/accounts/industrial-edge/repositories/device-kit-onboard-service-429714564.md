### Short excerpt (up to 100 words)

> The IE Device Kit API provides the abstraction layer that decouples the Industrial Edge Runtime from the underlying Linux systems. This allows to adapt the runtime and its behavior to serve for the specific needs of different Industrial Edge products. The IE Device Kit API is based on gRPC which provides a modern intermediate process communication style for building distributed applications and microservices.
