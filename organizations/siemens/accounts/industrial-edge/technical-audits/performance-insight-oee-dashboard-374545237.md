## Setup and usage

- Usage: Once the OEE configuration is done, the dashboard is automatically created underneath the dedicated asset. Go to *My Plant* and select the asset. Click on the *OEE* dashboard to open the view. Please be aware to select a proper time period for displaying the dashboard, that contains useful process data.
- Usage: The OEE dashboard offers the following views:
- Usage: - Quick overview of KPIs and machine status
- Usage: - Detail view for KPIs and machine status
- Usage: - Error analysis (optional):
- Usage: - Overview of the most common errors
- Usage: - Analysis of sub assets (optional):
- Usage: - Overview of machine states and OEE KPIs of all configured sub assets
