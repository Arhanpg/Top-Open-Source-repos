## Project purpose

You can create all MindSphere modelling artefacts (Variables, Aspect- and Asset Types as well as Assets) straight from a JSON Schema. This means that if you already have JSON data gathered from your industrial assets (e.g. because they are already available on your production data bus) you can leverage your existing JSON schemas (or extract them from JSON data) to quickly create all needed MindSphere artefacts.
