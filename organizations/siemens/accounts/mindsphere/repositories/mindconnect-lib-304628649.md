> This is the introductory document for MindConnect Library, abbreviated as MCL. Please check MCL reference documentation for details. MCL reference documentation can be accessed online or a local copy can be generated when building MCL (see MCL Build Options). MindConnect Library (MCL), is a cross-platform C library wrapping APIs that clients or agents can securely access over TLS v1.2. MindConnect Library is distributed as source code. The source code is organized as a core component and extensions to the core component. Onboarding, key rotation and access token retrieval functionalities will be available to agents with the **Core** component. Including **mcl_core.h**
