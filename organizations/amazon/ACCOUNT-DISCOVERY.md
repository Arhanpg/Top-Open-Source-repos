## Attribution and completeness rules

- The 29 additional accounts use the mapping status `official-directory-listed`.
- This records a relationship documented by the AWS open-source directory. It does not claim every account is legally owned by Amazon, nor that every repository was authored by AWS employees.
- Each GitHub account is inventoried independently. Repository ownership remains with the actual GitHub account.
- Archived repositories, forks, templates and mirrors should be retained and labelled from upstream metadata.
- The search probes are discovery checks only. Full account inventory requires the collector to follow every page of the public repositories API until GitHub returns no next-page link.
- Account inventory completion, evidence capture, manual README interpretation and company-wide account discovery are separate states.
