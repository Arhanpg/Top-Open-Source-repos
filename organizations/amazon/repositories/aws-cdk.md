## What it does

An open-source framework for defining cloud infrastructure in code and provisioning it through AWS CloudFormation.

## Features documented by the upstream README

- Uses object-oriented abstractions and reusable infrastructure constructs.
- Composes constructs into stacks and CDK applications.
- CLI can synthesize CloudFormation templates, deploy stacks and diff code against deployed infrastructure.
- Construct Library provides service-specific modules and APIs to reduce integration boilerplate.

## Technology stack

Supported languages listed in README: JavaScript, TypeScript (Node.js 20+), Python, Java, .NET and Go; AWS CloudFormation; AWS CDK CLI; Maven and language-specific package ecosystems.
