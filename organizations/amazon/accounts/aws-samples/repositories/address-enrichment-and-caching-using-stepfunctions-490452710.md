### Short excerpt (up to 100 words)

> Traditional methods of performing address enrichment on geospatial datasets can be expensive and time consuming. Using Amazon Location Service with AWS Step Functions for orchestration and with Amazon DynamoDB for caching in a serverless data processing pipeline, you may achieve significant performance improvements and cost savings on address enrichment jobs that use geospatial data. This sample is an evolution to the already available sample, which only uses Lambda functions (can be found here). Some of the improvements in this project includes: - Using AWS Step Functions for Orchestration - Using Amazon DynamoDB as a Naive cache to store location results,
