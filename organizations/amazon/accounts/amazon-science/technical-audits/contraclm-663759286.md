## Setup and usage

- Usage: bash runscripts/run_wikitext.sh
- Usage: 1. For quickly testing the code and debug, suggesting run the code with MLE loss only
- Usage: by setting CL_Config=$(eval echo ${options[1]}) within the script.
- Usage: 2. All other opotions involves CL loss at either token-level or sequence-level.
- Usage: 1. Configure the variables at the top of runscripts/run_code.sh. There are lots of options but only the dropout options are explained here (others are self-explanatory):
- Usage: * dropout_p: The dropout probability value used in torch.nn.Dropout
- Usage: * dropout_layers: If > 0, this will activate the last dropout_layers with probability dropout_p
- Usage: * functional_dropout: If specified, will use a functional dropout layer on top of the token representations output from the CodeGen model
