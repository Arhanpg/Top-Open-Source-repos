### Short excerpt (up to 100 words)

> Turn a real-world benchmark into a formally verified one. Benchproofer takes the tasks of an existing benchmark (SWE-bench, HumanEval, MBPP, QuixBugs, GSM8K, BigCodeBench, or your own file of tasks), formalizes each one into a specification plus an implementation a verifier checks, has each formalization attacked by a language model that did not write it, and then adjudicates the result mechanically. Every claim about a task is a verdict some gate produced and recorded, so anyone can re-run the gates on someone else's artifacts and get the same verdicts. Nothing certifies itself.
