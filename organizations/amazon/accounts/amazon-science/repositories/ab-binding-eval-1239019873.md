### Short excerpt (up to 100 words)

> This repository contains the training code for **MochiBind** and the evaluation framework used to benchmark baseline models for **antigen–antibody binding affinity prediction**, including **Graphinity**, **GeoDock**, and **Boltz2**. For details, refer to publication: A Systematic Evaluation Framework for Universal Antibody–Antigen Binding Affinity Prediction and Candidate Recommendation. The code supports model training on curated antibody–antigen datasets and standardized evaluation using pairwise and ranking-based metrics across multiple antigen systems. This code is being released solely for academic and scientific reproducibility purposes, in support of the methods and findings described in the associated publication.
