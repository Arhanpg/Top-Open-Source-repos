### Short excerpt (up to 100 words)

> ATTUNE turns a coding agent into a training-throughput tuner. Give it a working training recipe and a GPU-hour budget: it runs short benchmark jobs, profiles them, and changes one setting at a time to make the recipe faster. A correctness gate checks that a faster recipe still trains the same model before it ships. ATTUNE's recipes run in Amazon's production post-training, where they raise per-GPU throughput by 1.7× on average.
