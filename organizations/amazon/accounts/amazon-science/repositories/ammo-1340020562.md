### Short excerpt (up to 100 words)

> **AMMO (Agentic Model-on-Machine Optimizer)** is a multi-agent system that autonomously optimizes vLLM GPU kernels for a specific deployment — model, hardware, dtype, parallelism — over multi-hour unattended campaigns. This server creates and manages the isolated sessions those campaigns run in. Each session is a git worktree of vLLM with its own venv, a slice of the host's GPUs, and an AI CLI (Claude Code or Codex) running in a hardened terminal you drive from your browser. - **Hardware**: Linux host with an NVIDIA GPU (CUDA capability 8.0+ — A100, L40S, H100, H200, B200), CUDA 12.0+, and the NVIDIA container toolkit.
