### Short excerpt (up to 100 words)

> This utility reads a secret from AWS Secrets Manager and stores the keys from this secret to GitHub repository secrets. It is useful to maintain a set of keys across multiple repositories, handle rotation, etc. This tool is published as an npm module, so it can be either installed locally or globally via: npm i -g aws-secrets-github-sync Or any other npm package manager such as yarn, pnpm, etc. * GitHub CLI, logged into your account. * AWS credentials configured in your environment Use the AWS CLI or AWS Console to create a secret in AWS Secrets Manager that includes keys
