> This repository contains KIWI image descriptions for building various Linux distributions and configurations. Currently includes Amazon Linux 2023 (AL2023) and Amazon Linux 2027 (AL2027) attestable images with security-focused configurations. * **AL2023 Attestable Image**: Amazon Linux 2023 with TPM attestation, dm-verity protection. Creates an isolated compute environment * **AL2027 Attestable Image**: Amazon Linux 2027 with TPM attestation, dm-verity protection. Creates an isolated compute environment Build an image using KIWI: sudo kiwi-ng --color-output --loglevel 0 system build \ --description ./kiwi-image-descriptions-examples/<distribution>/<image-type> \ --target-dir ./image See CONTRIBUTING for more information.
