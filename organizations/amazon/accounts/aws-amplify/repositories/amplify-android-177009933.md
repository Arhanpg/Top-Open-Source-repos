> The Amplify Android library is AWS' preferred mechanism for interacting with AWS services from an Android device. The library provides a high-level interface to perform different **categories** of cloud operations. Each category may be fulfilled by a **plugin**, which you configure during setup. The default plugins that we provide are designed to facilitate interaction with Amazon Web Services (AWS). But, the Amplify Framework is designed to be extensible to any other backend or service.
