### Short excerpt (up to 100 words)

> This repository contains the source code for the AWS Amplify Discord Server's bot! - auto-threads "help" channels; if a channel follows the `<category>-help` naming convention messages will automatically get converted into threads - thread data is tracked by title, original poster ID, and whether the thread is solved (`GET /api/questions`) - dashboard component to visualize questions and channel "health" - support for GitHub to Discord webhooks (used for posting release notes) - command: `/admin mirror <repository>` accepts a REPOSITORY and posts the thread to GitHub Discussions - command: `/contribute` - accepts an Amplify project argument and returns the GitHub contribution
