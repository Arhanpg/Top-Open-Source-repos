### Short excerpt (up to 100 words)

> This CDK construct is used to include the CloudFormation resources generated by Amplify CLI Export command. The construct handles assets and CloudFormation files. It offers abstractions over the Amplify CLI generated cloud resources. The library is published under the following Install via NPM: npm i @aws-amplify/cdk-exported-backend@latest Add to your CDK app: import { AmplifyExportedBackend } from '@aws-amplify/cdk-exported-backend'; ... const amplifyExport = new AmplifyExportedBackend(app, 'AmplifyExportedBackend', { path: './amplify-export-myAmplifyApp', amplifyEnvironment: 'dev', }); The construct props extend stack props and can be used to override the root stack properties. Deploy this to your account cdk deploy We welcome community contributions and pull requests.
