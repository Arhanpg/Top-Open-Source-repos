> Amplify Swift Utilities for Notifications provides helpful functionality for working with push notifications on iOS and macOS. Although it was developed for use with AWS Amplify, it can also be used independently. - Convenience methods to support requesting notification permissions and registering with APNs - Push Notification Service extension to support fetching and attaching remote media to notifications Amplify Swift Utilities for Notifications package supports iOS 13+ and macOS 10.15+.
