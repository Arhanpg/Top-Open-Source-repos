> Ace (Ajax.org Cloud9 Editor) ============================ Ace is a code editor written in JavaScript. This repository has only generated files. To report your issues, suggest features, ask questions, or work on Ace editor itself please go to Ace repository https://github.com/ajaxorg/ace.
