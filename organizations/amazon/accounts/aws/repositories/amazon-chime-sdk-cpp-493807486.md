> The Windows client library builds on the C++ signaling client library by including a pre-compiled WebRTC implementation for Windows. So now, developers do not have to select, build and test a WebRTC library for their application. Developers still retain access to the audio and video frames for low-level integrations with microphone, speaker, and video devices. We also have an Amazon Chime SDK Project Board where you can find community requests and their statuses. To get started, see the following resources: * Amazon Chime * Amazon Chime Developer Guide * Amazon Chime SDK API Reference We currently distribute a Windows Binary
