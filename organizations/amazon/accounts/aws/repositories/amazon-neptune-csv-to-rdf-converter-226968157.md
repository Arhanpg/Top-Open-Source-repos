### Short excerpt (up to 100 words)

> A tool for Amazon Neptune that converts property graphs stored as comma separated values into RDF graphs. Amazon Neptune CSV to RDF Converter is a Java library for converting a property graph stored in CSV files to RDF. It expects an input directory containing the CSV files, an output directory, and an optional configuration file. The output directory will be created if it does not exist.
