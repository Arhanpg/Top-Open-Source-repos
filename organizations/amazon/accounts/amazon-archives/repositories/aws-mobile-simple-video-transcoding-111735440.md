## Upstream description

Add video transcoding to your Mobile App or Website, backed by AWS Mobile Hub. This will automatically transcode hi-res user-uploaded videos to an adaptive multi-bitrate format (HLS - Http Live Streaming) for easy streaming to mobile devices. This reduces bandwidth requirements, reduces playback buffering, and improves user experience in watching the videos.
