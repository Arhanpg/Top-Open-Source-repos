### Short excerpt (up to 100 words)

> A static site demonstrating real-time audio transcription via Amazon Transcribe over a WebSocket. This demo app uses browser microphone input and client-side JavaScript to demonstrate the real-time streaming audio transcription capability of Amazon Transcribe using WebSockets. Check out the Amazon Transcribe WebSocket docs. Even though this is a static site consisting only of HTML, CSS, and client-side JavaScript, there is a build step required. Some of the modules used were originally made for server-side code and do not work natively in the browser. We use browserify to enable browser support for the JavaScript modules we `require()`. 1.
