### Short excerpt (up to 100 words)

> This repository is a collection of code snippets for working with different parts of Amazon Connect. The snippets are organized by language. There's an additional directory called `tools` and a collection of projects that come with associated CloudFormation templates and Contact Flows in the `projects/` directory. We currently have snippets in: * Python under python/ * Java under java/ * DotNet (C#) under dotnet/ * Javascript under javascript/ * Go under go/ * PowerShell powershell/ * Tools tools/ Feel free to add more languages. Please follow the requirements in each subdirectory README. Make sure the `.gitignore` per language is applied.
