### Short excerpt (up to 100 words)

> **Status: pre-release.** The public API will change without notice until a 1.0 release is tagged. Native iOS SDK for Amazon Connect Customer Touchpoint: chat, outbound voice, and Live Sync, as separately linkable Swift packages so an app pays only for the modalities it uses. A chat-only consumer never links the WebRTC media stack. `Scripts/check-build-graph.sh` enforces that on every `make check` by walking the transitive product graph of every resolved package, so an upstream dependency pulling Chime in would fail the gate too. iOS 17.0+, Swift 6 language mode, Swift Package Manager. Xcode 26 or newer to build the iOS products;
