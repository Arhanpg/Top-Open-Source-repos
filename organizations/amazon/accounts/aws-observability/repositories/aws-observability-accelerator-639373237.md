> Welcome to the AWS Observability Accelerator! The AWS Observability Accelerator help you set up observability for your AWS environments with AWS-managed observability services such as Amazon Managed Service for Prometheus, Amazon Managed Grafana, AWS Distro for OpenTelemetry (ADOT) and Amazon CloudWatch. This repository provide shared artifacts (documentation, dashboards, alerting rules) for the Terraform and CDK projects. This repository also serves as a GitOps source repository.
