### Short excerpt (up to 100 words)

> Welcome to the AWS Observability Accelerator for Terraform! The AWS Observability Accelerator for Terraform is a set of opinionated modules to help you set up observability for your AWS environments with AWS-managed observability services such as Amazon CloudWatch, Amazon Managed Service for Prometheus, Amazon Managed Grafana, and OpenTelemetry. We provide curated metrics, logs, traces collection, alerting rules and Grafana dashboards for your AWS infrastructure and custom applications. To explore the complete project documentation, please visit our documentation site. The EKS monitoring module offers three collector profiles. Pick the one that matches your observability backend: All profiles deploy kube-state-metrics and node-exporter
