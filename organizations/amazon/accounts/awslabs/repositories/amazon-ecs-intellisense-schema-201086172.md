### Short excerpt (up to 100 words)

> This package is to provide an intelligent code completion (IntelliSense) experience for users when writing an Amazon ECS task definition in their Visual Studio Code or JetBrains IDEs. It does so by parsing the Amazon ECS model files from the AWS SDK for Go. With these files, the package generates a JSON schema file that provides code completion, documentation lookup, and error checking. Instructions to build and enable IntelliSense are down below. Here is a VSCode setup integration example: 1. Configure your IDE settings by going to `Code` → `Preferences` → `Settings` 2. In the search bar, type in settings.json
