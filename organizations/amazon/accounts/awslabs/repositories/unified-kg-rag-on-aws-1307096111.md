## Upstream description

AWS-native knowledge graph RAG framework. Runs GraphRAG, LightRAG, HippoRAG 2 and RAPTOR on one shared index, each selectable at index and query time, with hybrid BM25 + vector + graph retrieval and source provenance. Amazon Bedrock, Neptune and OpenSearch, or fully local. Incremental indexing, multilingual, bring-your-own KG, built-in evaluation.
