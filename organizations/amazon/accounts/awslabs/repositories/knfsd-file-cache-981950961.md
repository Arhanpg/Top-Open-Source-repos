## Upstream description

A set of utilities for building, deploying and operating a high performance NFS Cache in Amazon Web Services. This is designed to be used for certain HPC and burst compute use-cases where there is a requirement for a high performance NFS cache between a NFS Server and its downstream NFS Clients.
