### Short excerpt (up to 100 words)

> Command-line tools for [AWS Controllers for Kubernetes][ack] (ACK). Run `ackctl <command> --help` for flags and examples. Needs Go 1.24 or newer. go install github.com/aws-controllers-k8s/ackctl/cmd/ackctl@latest That installs the `ackctl` binary into `$(go env GOPATH)/bin`, which must be on your `PATH`. Pin a specific release instead of `@latest` with `...cmd/ackctl@v0.0.1`. Verify, and check what you installed: ackctl version From a clone: make build # -> bin/ackctl make install # -> $GOPATH/bin/ackctl Adopt every EKS Nodegroup tagged `Environment=prod`: ackctl adopt --service eks --kind Nodegroup --tag Environment=prod | kubectl create -f - Manifests go to stdout; nothing is applied to a cluster for you.
