### Short excerpt (up to 100 words)

> **AWS Controllers for Kubernetes (ACK)** lets you define and use AWS service resources directly from Kubernetes. With ACK, you can take advantage of AWS managed services for your Kubernetes applications without needing to define resources outside of the cluster or run services that provide supporting capabilities like databases or message queues within the cluster. ACK is an open source project built with ❤️ by AWS. The project is composed of many source code repositories containing a [common runtime][runtime-repo], a Kubernetes custom controllers for individual AWS service APIs. * Overview * Getting Started * Help & Feedback * Contributing * License
