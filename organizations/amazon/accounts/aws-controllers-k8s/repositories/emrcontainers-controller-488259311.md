### Short excerpt (up to 100 words)

> This repository contains source code for the AWS Controllers for Kubernetes (ACK) service controller for EMR on EKS Service. Please log issues and feedback on the main AWS Controllers for Kubernetes (ACK) Github project. The ACK service controller for EMR on EKS provides declarative way to run spark jobs on EKS clusters. EMR on EKS manages the lifecycle of these jobs and it uses highly optimized EMR runtime 3.5 times faster than open-source Spark when you run these jobs.
