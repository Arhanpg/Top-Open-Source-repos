### Short excerpt (up to 100 words)

> A Python library for reading, creating, and editing Apple Creator Studio documents, starting with Keynote. This library works with Keynote presentations in Keynote Interchange Format (`.keyx`). You can use it to: - Read the slides, text, images, tables, charts, styles, and more in a `.keyx` file exported from Keynote. - Create a presentation from scratch, or from a theme's slide layouts and styles. - Edit a presentation, and check it against the format's rules before you save it. The library reads and writes `.keyx` files itself, so it doesn't need Keynote, an Apple device, or a network connection. To preview
