### Short excerpt (up to 100 words)

> The Swift-DocC plugin is a Swift Package Manager command plugin that supports building documentation for SwiftPM libraries and executables. Please see for more detailed usage instructions. To use the Swift-DocC plugin with your package, first add it as a dependency: let package = Package( // name, platforms, products, etc. dependencies: [ // other dependencies .package(url: "https://github.com/swiftlang/swift-docc-plugin", from: "1.1.0"), ], targets: [ // targets ] ) Swift 5.6 is required in order to run the plugin. You can then invoke the plugin from the root of your repository like so: swift package generate-documentation This will generate documentation for all compatible targets
