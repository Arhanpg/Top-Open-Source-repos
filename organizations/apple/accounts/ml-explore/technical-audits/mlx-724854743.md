## Project purpose

MLX is an array framework for machine learning on Apple silicon, developed by Apple's machine learning research team.

## Why this project is used

Researchers can build and experiment with machine-learning models using familiar array APIs, automatic differentiation and vectorization, and CPU/GPU execution on supported Apple silicon systems.

## Core features

- **Familiar multi-language APIs:** Python, C++, C and Swift APIs, with higher-level mlx.nn and mlx.optimizers packages. Evidence: README.md#MLX.
- **Composable function transformations:** automatic differentiation, automatic vectorization and graph optimization. Evidence: README.md#MLX.
- **Lazy and dynamic computation:** lazy evaluation and dynamic computation graphs. Evidence: README.md#MLX.
- **Multi-device execution:** CPU/GPU execution with shared-memory arrays for supported devices. Evidence: README.md#MLX.

## Technology stack

- **Languages:** C++, Python, C, Swift, Metal
- **Frameworks/libraries:** MLX, mlx.nn, mlx.optimizers
- **Build/package tools:** CMake, setuptools, pip
- **Build dependencies:** setuptools, cmake, typing_extensions
- **Runtimes/APIs:** Python, C++, C, Swift
- **Platforms:** Apple silicon macOS; Linux CPU/CUDA packages

## Architecture

The README describes a lazy array framework with CPU/GPU backends and composable graph transformations. CMake configuration exposes CPU, Metal and optional CUDA build paths. Internal implementation architecture was not exhaustively inspected.

## Setup and usage

The README documents pip installation for macOS and separate CPU/CUDA package extras for Linux. CMake configuration is provided for source builds.

## Limitations and caveats

- The project is primarily positioned for Apple silicon; consult current installation instructions for supported hardware and OS combinations.
- The inspected CMake configuration makes Metal platform-specific and keeps CUDA optional.
- Broader model examples are maintained in a separate mlx-examples repository and should not all be attributed to this codebase.
