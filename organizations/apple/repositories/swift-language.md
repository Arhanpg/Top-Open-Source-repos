## Project overview

The primary source repository for the Swift programming language. The README describes Swift as a high-performance system-programming language with modern syntax, memory safety by default and interoperability with existing C and Objective-C code and frameworks.

## Features and capabilities documented by the README

- Combines flow control, data structures and functions with objects, protocols, closures and generics.
- Uses modules rather than traditional header files, reducing code duplication and separate declarations.
- Targets systems programming, mobile and desktop apps, cloud services and embedded firmware.
- Contains language implementation, compiler-related source and tooling; related Swift package-manager and documentation projects are maintained in other repositories in the swiftlang organization.
- Provides contributor guidance, first-pull-request instructions, FAQs and toolchain-building documentation.
- Documents toolchain packaging and installation into Xcode, including debug-symbol archives.

## Getting started

Start with the Swift.org Getting Started and contribution guides. For compiler development, follow the repository build-script documentation; the README describes utils/build-toolchain for producing local toolchains and optional dry-run, test, distcc and sccache modes.
