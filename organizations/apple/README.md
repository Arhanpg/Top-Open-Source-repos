## Project themes

The two reviewed repositories illustrate distinct areas of open-source engineering: local developer infrastructure for Apple-silicon Macs and distributed transactional data storage. They should not be treated as representative of every Apple technology area or as a complete inventory of Apple's open-source activity.

## How to explore these projects

- For the container tool, start with its macOS and hardware requirements, OCI image workflow and separate Containerization Swift package.
- For FoundationDB, start with the data model, transaction guarantees, documentation and currently supported release branches.

## Inventory status and cautions

The Apple organization folder contains only projects whose README pages have been reviewed for this catalogue. Repository enumeration is not complete. Do not infer that a project is an Apple-supported commercial product solely because it appears under a GitHub account with Apple's name. Follow each project's upstream documentation, licence and support statements.
