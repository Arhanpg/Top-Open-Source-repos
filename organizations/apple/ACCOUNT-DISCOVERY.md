## Attribution and scope

- official-project-linked records an Apple-managed project page with a direct link to the GitHub account. It does not assert that every repository in that account is legally owned by Apple or authored by Apple employees.
- GitHub repository ownership remains with the account shown in each upstream URL.
- Apple's official catalogue also lists community projects that Apple participates in (for example Kubernetes, Apache Cassandra, LLVM, Open Policy Agent and Apache Spark). Those projects are not attributed to Apple-owned accounts unless the source explicitly links an Apple-controlled account.
- The two additional accounts in this register are partial project-based coverage. This does not prove that no other Apple-associated GitHub accounts exist.

## Inventory status

The current Apple account set comprises the primary apple organization and two additional project-linked accounts. Each account requires independent public-repository pagination before the wider Apple account inventory can be marked complete.
