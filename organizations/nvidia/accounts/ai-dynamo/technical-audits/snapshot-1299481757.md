## Project purpose

Snapshot is a Kubernetes-native checkpoint and restore system for NVIDIA GPU workloads. It checkpoints a fully initialized GPU pod (its running process, with CPU and GPU memory) and restores that state on any compatible node, so a pod becomes ready in seconds instead of minutes.

## Why this project is used

Snapshot gets GPU pods ready in seconds instead of minutes — by restoring a fully initialized GPU worker instead of starting one from scratch. Kubernetes-native checkpoint & restore that runs alongside your existing stack.

## Limitations and caveats

- Limitations: - Linux nodes on x86_64 or arm64.
- Limitations: - Workloads, including multi-GPU workloads, must run on a single node. Multi-node is on the roadmap.
- Limitations: - vGPU is not supported.
- Limitations: - Runs only on NVIDIA GPUs supported by the required CUDA driver.
- Security: To report a security vulnerability, follow the process in SECURITY.md.
