## Project purpose

RadixShmem is a KV cache index built on a distributed radix tree. Each node keeps its own radix tree in POSIX shared memory, which any process on the node can attach to and insert or look up KV cache blocks by prefix hash. Across nodes, a sharded Radix Hash Table (RHT) records which node holds each prefix, and a query continues the match on that peer's tree, so the KV cache is indexed globally across the cluster. With a transfer engine (Mooncake or NIXL), RadixShmem also moves the blocks between nodes.
