### Short excerpt (up to 100 words)

> --> **Run larger models within your GPU memory budget.** FlexTensor is a weight-offloading library for large-model inference, supporting PyTorch models and integration with vLLM. It keeps selected model weights in CPU RAM and streams them to the GPU as needed, helping you run models whose weights would otherwise exceed available GPU memory without reducing model size or precision. FlexTensor profiles execution and prefetches upcoming weights to overlap transfers with GPU computation. This can hide transfer overhead in compute-heavy workloads. The achievable memory savings and inference speed depend on your model, workload and CPU–GPU bandwidth. FlexTensor is actively developed at NVIDIA,
