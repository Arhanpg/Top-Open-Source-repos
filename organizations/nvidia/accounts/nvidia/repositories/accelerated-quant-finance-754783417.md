### Short excerpt (up to 100 words)

> This project contains two sample applications relevant to quantitative finance. These examples are intended to demonstrate how ISO C++ can be used to write code parallel code that is portable to CPUs and GPUs. This code is intended solely for illustration and should not be used in production environments. In the first example, we consider a large universe of options, generated by sampling option strikes, maturities, and volatilities on a 3D grid. The Black-Scholes valuation of calls and puts with these parameters is perfectly parallelizable, so it scales well to multicore CPUs or GPUs. A CPU baseline code is provided
