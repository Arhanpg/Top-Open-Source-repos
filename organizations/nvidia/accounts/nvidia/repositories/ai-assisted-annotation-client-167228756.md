> NVIDIA AI-Assisted Annotation SDK follows a client-server approach to integrate into an application. Clara Train SDK container on ngc.nvidia.com is generally available for download, annotation server is included in the package. Once a user has setup the AI-Assisted Annotation Server, user can use either C++ or Python client to integrate the SDK into an existing medical imaging application.
