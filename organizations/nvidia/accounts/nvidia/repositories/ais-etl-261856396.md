### Short excerpt (up to 100 words)

> This repository contains the components and examples used to run **Extract-Transform-Load (ETL)** operations on an AIStore cluster. For more information on how ETL works in AIStore, refer to the following documentation: - AIS ETL Docs - AIS ETL CLI Docs - AIS Python SDK Docs (includes ETL usage) - transformers — ready-to-use ETL transformers that can be deployed on an AIStore cluster - runtime — ETL runtime definitions for `init_class` function To begin using ETLs in AIStore, deploy an AIStore cluster on Kubernetes using an ETL-enabled `aisnode` build. ETL is excluded from the default AIStore build and image. Official releases
