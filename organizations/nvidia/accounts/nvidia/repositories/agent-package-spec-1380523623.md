### Short excerpt (up to 100 words)

> This repository proposes a standard way to package and distribute **agent skills and agent plugins as OCI artifacts**. The aim is to give publishers, registries, marketplaces, and agent hosts a common distribution format that works with existing OCI tooling for versioning, signing, verification, and promotion. The draft specification preserves the native Skill or Plugin files and adds an OCI manifest, package metadata, and a verifiable file inventory around them.
