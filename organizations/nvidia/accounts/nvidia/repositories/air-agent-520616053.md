### Short excerpt (up to 100 words)

> The NVIDIA Air Agent is a systemd service that detects if a VM has been cloned. When a clone operation has been detected, it calls out to the Air API to see if there are any post-clone instructions available to execute. Make sure `python3` and either `python3-pip` are installed: sudo apt update && sudo apt install -y python3 python3-pip Install the dependencies via pip: python3 -m pip install . Make sure `python3`, `python3-cryptography`, `python3-git`, `python3-requests` and `util-linux-extra` (required for use of the `hwclock` command by the agent) are installed: sudo apt update && sudo apt install -y python3 python3-cryptography python3-git
