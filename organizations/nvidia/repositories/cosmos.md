## Project overview

NVIDIA Cosmos is described as an open platform for building physical-AI applications. The README presents world foundation models and related tools for generating, reasoning about and simulating physical environments, with target sectors including robotics, autonomous vehicles, manufacturing, smart infrastructure, healthcare and agriculture.

## Features and capabilities

- Introduces a Cosmos model family and links model checkpoints, technical reports and a project website.
- Demonstration categories include physics-aware video generation, scenario transfer, action policies, simulation, action-conditioned world models and world reasoning.
- Provides browser demonstrations, quickstart instructions and a cookbook for selected workflows.
- Links model and deployment paths for robotics, autonomous-driving and physical-AI applications.
- Contains explicit limitations and safety sections and references model-specific technical reports and licences.

## Technology stack

Physical-AI/world-model research platform; model artifacts are distributed through NVIDIA's Hugging Face collections. The repository README links model-family documentation, technical reports, cookbooks and demo services. Exact framework/runtime dependencies must be checked per model and example.

Start from the README's Find Your Path guide and Generate Your First Video quickstart. Select the relevant model and read its model card, licence and technical report before provisioning hardware or downloading checkpoints.
