## What it does

An inference optimization framework for large language models and visual-generation models, using specialized kernels, an efficient runtime and a Python-oriented extensibility layer.

## Features documented by the upstream README

- Specialized kernels for common model operations.
- Efficient runtime for LLM and visual-generation inference.
- Pythonic framework that can be customized and extended.
- README links architecture, performance, quick-start examples, roadmap and technology articles.
