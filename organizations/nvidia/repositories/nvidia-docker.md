## Project overview

This repository previously provided tooling for configuring Docker to use NVIDIA GPUs. Its current README is a deprecation notice and directs users to NVIDIA Container Toolkit.

## Features and capabilities

- The upstream README states the project has been superseded by NVIDIA Container Toolkit.
- The nvidia-docker wrapper is no longer supported and the repository is archived.
- The replacement toolkit provides the supported path for configuring Docker to use NVIDIA Container Runtime.
- The README redirects issues, feature requests and bug reports to the replacement project.

## Technology stack

Historical Docker/NVIDIA GPU integration tooling. The README does not present a supported current implementation stack because the repository is archived and deprecated.

## Getting started

Do not start a new integration with this repository. Follow the NVIDIA Container Toolkit installation guide and current documentation instead.
