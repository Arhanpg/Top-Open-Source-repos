## Attribution caveats

- The NVIDIA hub links these accounts/projects as part of its open-source project portfolio.
- The `official-project-linked` status is not a blanket legal-ownership claim for the entire GitHub account.
- Projects explicitly marked as upstream community contributions on the NVIDIA hub (such as PyTorch, vLLM, SGLang, Linux, Kubernetes and Pixar/OpenUSD) are not added to NVIDIA's company-account inventory.
- Repository ownership remains with the actual GitHub account. Each account receives an independent paginated inventory.

## Scope and completion

The NVIDIA catalogue now maps six accounts: the primary verified `NVIDIA` organization plus five official project-linked accounts. This does not prove that no other NVIDIA-associated GitHub accounts exist. Full company-wide account discovery remains open.
