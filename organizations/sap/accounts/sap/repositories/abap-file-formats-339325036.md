### Short excerpt (up to 100 words)

> This project provides file format definitions of [ABAP repository objects][1]. The project is still in an early phase. We plan to modify and extend this document as our understanding improves. Since the ABAP file formats can still change in the future, we do not recommend using them in a productive environment, yet. ABAP repository objects are stored on development systems and not as regular text files like in many other programming languages including python, C++ and others. The aim of the ABAP file formats is to provide a common and transparent definition of how to store ABAP repository objects in
