### Short excerpt (up to 100 words)

> The document describes events that comply with the _CloudEvents specification for SAP ecosystem_ and additional SAP-specific extensions. The goal of these extensions is to describe a standardized event catalog format that enables a central and uniform event publication and event discovery. It is used to publish content on SAP Business Accelerator Hub. These extensions are based on the AsyncAPI Specification 2.0.0. Every document following the schema defined in this document is also a valid AsyncAPI 2.0 document.
