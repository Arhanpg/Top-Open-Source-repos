## Project purpose

SAP provides dedicated ABAP Open Source Namespaces exclusively for open source projects. This repository lists all existing namespaces, including development and repair keys for DEMOSYSTEM installations such as the ABAP Cloud Developer Trial (formerly known as miniSAP).

## Why this project is used

ABAP open source projects can register own namespaces. This repository lists all known ones and provides development and repair keys for the ABAP Cloud Developer Trial system.
