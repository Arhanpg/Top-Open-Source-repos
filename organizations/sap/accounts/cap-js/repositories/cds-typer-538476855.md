### Short excerpt (up to 100 words)

> Generates `.ts` files for a CDS model to receive code completion in VS Code. Exhaustive documentation can be found on CAPire. Certain language features of CDS can not be represented in TypeScript. Trying to generate types for models using these features will therefore result in incorrect or broken TypeScript code. While the following is valid CDS, there is no TypeScript equivalent that would allow the type of an inherited property to change (TS2416). entity A { foo: Integer }; entity B: A { foo: String } This project is open to feature requests/suggestions, bug reports etc. via GitHub issues.
