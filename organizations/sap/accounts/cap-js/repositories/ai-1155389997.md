### Short excerpt (up to 100 words)

> `@cap-js/ai` adds UI recommendations powered by SAP AI Core, simplified access to SAP AI Core resources, and vector embedding support for CAP applications. The plugin adds SAP-RPT-1 recommendations to draft-enabled entities. Fields with a value help are included automatically: @odata.draft.enabled entity Books { key ID : Integer; title : String; genre : Association to Genres; price : Decimal; } annotate Genres with @cds.odata.valuelist; Use `@UI.RecommendationState` to opt individual fields in or out: annotate Books with { genre @UI.RecommendationState: 0; price @UI.RecommendationState; } A production deployment requires an SAP AI Core service binding. Without one, local development uses a mock implementation
