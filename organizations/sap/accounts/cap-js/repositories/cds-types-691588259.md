### Short excerpt (up to 100 words)

> Contains type definitions for the Node.js SDK of the SAP Cloud Application Programming Model (CAP). Just install package `@sap/cds` into a Javascript or Typescript project, and the types will automatically be available in modern IDEs like VS Code. Find more information on the APIs in the Node.js SDK documentation. If you rename your project after you installed the type definitions on Windows, you have to rerun `npm install` to correctly recreate the symlink `node_modules/@types/sap__cds`.
