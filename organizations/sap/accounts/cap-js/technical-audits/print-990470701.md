## Setup and usage

- Usage: To use this plugin to print documents, there are two main steps:
- Usage: 1. Ensure your model meets the requirements
- Usage: 2. Annotate your CDS model with @PDF.Printable
- Manual Usage: You can also use the print service to print documents manually, i.e., without the @PDF.Printable annotations and generated actions and handlers.
- Manual Usage: Use cases for a manual approach could be:
- Manual Usage: - You want to print documents that are not part of your CDS model, i.e., files generated at runtime.
- Manual Usage: - Your model does not meet the requirements for the automatic approach.
- Manual Usage: - You want to print a file type other than PDF.
