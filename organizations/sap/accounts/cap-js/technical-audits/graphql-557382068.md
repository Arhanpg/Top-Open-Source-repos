## Project purpose

A GraphQL protocol adapter for SAP Cloud Application Programming Model Node.js. This adapter generically generates a GraphQL schema for the models of an application and serves an endpoint that allows you to query your services using the GraphQL query language.

## Why this project is used

## Limitations and caveats

- Limitations: - **Actions** and functions are not yet supported.
- Limitations: - **CDS annotations** like @readonly aren’t considered during schema generation.
- Limitations: - **Cursor-based Pagination** &ndash; we currently support offset-based pagination, and will add cursor-based pagination going forward. While we intend to support both variants then, it is not guaranteed that we can do so without breaking changes to current behaviour.
- Limitations: - **Extensions** are not yet considered.
