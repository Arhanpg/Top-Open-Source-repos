## Setup and usage

- Download and Installation: Use the abapGit plug-in to install the JSON ABAP Konverter by executing the following steps:
- Download and Installation: * In ADT create the package /DMO/JAK as a subpackage under /DMO/SAP (keep the defaulted values)
- Download and Installation: * In ADT click on Window > Show View > Other... and choose the entry abapGit Repositories to open the abapGit view
- Download and Installation: * Make sure to have the correct ABAP Cloud Project selected (See the little headline in the abapGit view for the current project)
- Download and Installation: * Click on the + icon to clone an abapGit repository
- Download and Installation: * Provide the URL of this repository: https://github.com/SAP/abap-platform-jak.git
- Download and Installation: * On the next page choose the master branch and provide the package /DMO/JAK
- Download and Installation: * Provide a valid transport request and choose Finish. This starts the cloning of the repository - which might take a few minutes
