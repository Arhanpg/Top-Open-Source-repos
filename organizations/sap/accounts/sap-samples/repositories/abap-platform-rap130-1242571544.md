### Short excerpt (up to 100 words)

> This repository contains the material of the hands-on session **RAP130 - Build apps and web APIs with ABAP Cloud using agentic AI**. It describes how to build a transactional SAP Fiori elements app for travel management using the **ABAP RESTful Application Programming Model (RAP)**. You use **Visual Studio Code** and the **ABAP Development Tools for VS Code (ADT)** extension to access and develop ABAP source code in the ABAP system. ADT contains the integrated **ADT MCP server** that enables to generate a RAP UI service and to enhance your application using the **ADT MCP tools**. For agentic AI-based ABAP development
