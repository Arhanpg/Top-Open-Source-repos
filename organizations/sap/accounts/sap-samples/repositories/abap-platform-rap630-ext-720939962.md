### Short excerpt (up to 100 words)

> --> This repository contains additionial material for the RAP hands-on workshop called _RAP630 - Use ABAP Cloud for developer extensibility_. It contains the source code of the solution for the extension of the package **ZRAP630_SOL**. The source code is stored in a separate GitHub repository so that it is possible to install **ZRAP630_SOL** and **ZRAP630_SOL_EXT** in two different software components. In the script both packages are both stored in **ZLOCAL** so that the exercises can also be performed in shared trial systems.
