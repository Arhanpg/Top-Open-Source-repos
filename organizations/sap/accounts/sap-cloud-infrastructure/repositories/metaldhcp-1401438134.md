### Short excerpt (up to 100 words)

> A DHCP server for bare-metal out-of-band networks. It is built on the coredhcp library — not a fork — and adds a single custom plugin, `oob`, for Kubernetes-native address management. The `oob` plugin handles IPv4 address allocation (DHCPv4 `server4`) and lease persistence: - **Address pools** come from two sources (mutually exclusive): - *Inline subnets* — defined in the plugin config file (`subnets:`), managed by the deployment pipeline or Helm. When present, these are authoritative. - *Subnet CRs* — selected by label (`subnetLabels:`), synced into the cluster by a separate operator. Used when no inline subnets are configured. - **DHCP relay
