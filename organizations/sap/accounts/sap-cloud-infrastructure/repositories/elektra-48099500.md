### Short excerpt (up to 100 words)

> Elektra is an opinionated Openstack Dashboard for Operators and Consumers of Openstack Services. Its goal is to make Openstack more accessible to end-users. To that end Elektra provides web UIs that turn operator actions into user self-services. **User self-services:** - User onboarding - Project creation and configuration - Quota requests - Authorizations and access control for projects and services - Cost control **We have UIs for the following Openstack core services**: - Compute: servers, server images, server snapshots (Nova) - Block storage: volumes, volume snapshots (Cinder) - User and group roles assignments (Keystone) - Secure key store (Barbican) - Software-defined
