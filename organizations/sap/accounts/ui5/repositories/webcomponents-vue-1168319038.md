### Short excerpt (up to 100 words)

> The project provides means for creating Vue components out of UI5 Web Components, providing a seamless integration of pure web components in Vue. UI5 Web Components are framework-agnostic custom elements, but using them directly in Vue lacks TypeScript support, v-model compatibility, and native slot syntax. This library wraps them to provide a first-class Vue development experience. - **EXPERIMENTAL**: This project is currently in an experimental phase. The API may change in future releases without prior notice. - **Vue Compatibility**: Requires Vue **^3.5.27** or higher.
