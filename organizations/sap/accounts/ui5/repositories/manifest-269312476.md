### Short excerpt (up to 100 words)

> This project contains a JSON schema for the UI5 manifest. This JSON schema for the UI5 manifest is meant to be referenced in the JSON Schema Store. This provides validation and code completion of the `manifest.json` file in SAP Business Application Studio or other IDEs. TypeScript type definitions are available for schema code completion, documentation, and type checking within IDEs. The package exports a runtime validation API so you can validate a manifest against a UI5 manifest schema programmatically. By default it validates against the `schema.json` shipped with this package — you don't need to load a schema yourself: import
