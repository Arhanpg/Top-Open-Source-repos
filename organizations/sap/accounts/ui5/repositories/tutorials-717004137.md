> These tutorials cover OpenUI5 application development, from beginner foundations to focused deep dives on specific concepts. Along the way you'll also use the UI5 CLI for local development tooling. All tutorials (everything except Agentic Development) are available in both **TypeScript** and **JavaScript** — use the language toggle at the top of each tutorial page to switch between versions.
