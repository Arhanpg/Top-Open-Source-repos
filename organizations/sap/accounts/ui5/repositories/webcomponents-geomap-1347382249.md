### Short excerpt (up to 100 words)

> Geomap Web Component for visualizing geospatial data based on UI5 Web Components. The Geomap component can visualize GeoJSON data from various map/tile providers like ESRI, MapBox, Azure Maps, SAP HSS, etc. It can mix the tiles provided by the map provider and GeoJSON describing features and layers coming from another source(s) and visualize the different layers to represent these features. Some of the main map features are: - Visualize, pan, zoom, rotate, tilt the map - Supports different features like point, line string, polygon, etc. - Highly customizable markers on the fly - Clustering of objects on the map when
