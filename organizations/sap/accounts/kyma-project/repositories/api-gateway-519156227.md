### Short excerpt (up to 100 words)

> API Gateway is a Kyma module with which you can expose and secure APIs. The API Gateway module offers the following features: - API Exposure: The module uses Istio features to help you easily and securely expose your workloads by creating APIRule custom resources. With an APIRule, you can perform the following actions: - Group multiple workloads and expose them under a single host. - Use a short host name to simplify the migration of resources to a new cluster. - Configure the **noAuth** access strategy, which offers a simple configuration to allow access to specific HTTP methods. - Secure
