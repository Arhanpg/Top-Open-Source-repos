### Short excerpt (up to 100 words)

> The GPU module manages the NVIDIA GPU Operator lifecycle on SAP BTP, Kyma runtime clusters. It handles installation, upgrades, and health monitoring through a single `Gpu` custom resource. The operator embeds the NVIDIA GPU Operator Helm chart and Garden Linux driver values directly in the binary - no network access is needed during reconciliation. Garden Linux clusters use pre-compiled drivers (no runtime kernel module compilation). Ubuntu clusters use standard NVIDIA images. - A Kyma cluster with GPU machine types (AWS g4dn/g6, GCP g2, Azure Standard_NC) - kubectl 1. Install the GPU operator (CRD, RBAC, and controller): kubectl apply -f https://github.com/kyma-project/gpu/releases/latest/download/install.yaml
