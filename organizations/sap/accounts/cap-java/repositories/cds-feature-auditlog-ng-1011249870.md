### Short excerpt (up to 100 words)

> The CDS plugin for SAP Audit Log service enables Java CAP applications to emit audit log events in a standardized way. It is fully compatible with the Audit Log Event Catalog, ensuring standardized event semantics and compatibility. You can emit the following types of audit log events: - Personal Data Access Event - Personal Data Modification Event - Configuration Change Event - Security Event Official CAP documentation can be found here. For both local and cloud testing, refer to the cloud-cap-samples-java repository and follow the instructions provided in its README. For local testing, make sure to create a default-env.json file
