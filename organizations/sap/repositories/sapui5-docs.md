## Project overview

The source repository for the Markdown documentation that feeds the official SAPUI5 Demo Kit. It allows developers and users to propose fixes and improvements to SAPUI5 documentation directly in GitHub.

## Features and capabilities documented by the README

- Stores documentation pages as Markdown files in the docs directory.
- Accepts contributions that correct errors, clarify procedures or add steps that help developers use SAPUI5.
- Connects the official SAPUI5 Demo Kit's Edit workflow to the corresponding GitHub Markdown source file.
- Allows small suggestions directly from the Demo Kit and larger contributions through a local fork.
- Uses filenames based on the title of the corresponding SAPUI5 Demo Kit page.
- Documents contribution expectations and links to SAP's Open Documentation Initiative guidelines and Code of Conduct.

## Technology stack

Markdown documentation source; GitHub pull-request/fork workflow; SAPUI5 Demo Kit as the publication destination; SAP Open Documentation Initiative contribution guidelines. This repository is a documentation source, not the SAPUI5 JavaScript framework implementation.

## Getting started

Open the relevant page in the SAPUI5 Demo Kit and choose Edit to reach its Markdown source. For larger changes, fork this repository and edit the corresponding file under docs. Contributions are reviewed; valuable accepted changes are added to the official SAPUI5 Demo Kit documentation.

## Lifecycle, compatibility and operational considerations

The README states that contributions to Markdown files in docs are reviewed and, if considered valuable, added to the official Demo Kit. Do not describe a commit to this source repository as an immediate change to the published documentation. Check the repository LICENSE and SAP Open Documentation Initiative contribution guidance for exact copyright and licence terms.
