## Project themes

These projects represent two useful but different parts of the software ecosystem: a foundational Java library and a Python package for AI-assisted information extraction. Guava is relevant to application/library engineering, while LangExtract is relevant to document processing, LLM integration and traceable data extraction.

## Technology snapshot

- **Guava:** Java, JDK 8+ JRE flavour, Android-compatible flavour, Maven and Gradle integration.
- **LangExtract:** Python 3.10+, setuptools packaging, Pydantic / NumPy / Pandas / PyYAML and provider integrations for Gemini, Ollama and optional OpenAI, as reflected in its inspected package manifest.
