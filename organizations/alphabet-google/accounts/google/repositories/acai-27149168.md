### Short excerpt (up to 100 words)

> Acai makes it easy to write functional tests of your application with JUnit 4 and Guice. Acai makes it simple to: - Inject the helper classes you need into tests - Start any services needed by your tests - Run between-test cleanup of these services - Start up multiple services for testing in the right order - Create test scoped bindings Acai is designed for large functional tests of your application.
