### Short excerpt (up to 100 words)

> Account provisioning for Google Apps is an open source API to: * **Generate available usernames** in your Google Apps domain * **Create Google Apps accounts** in your domain It can be used in a website where users create their own accounts... a script that creates accounts in bulk... or via a CSV input... Usernames are generated automatically via configurable patterns. Sample images are taken from the included demos. Give them a try here! This API can be installed as a RESTful service (to be invoked from almost any programming language and platform) or as a Java library. Google Apps deployments
