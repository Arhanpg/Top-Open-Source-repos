### Short excerpt (up to 100 words)

> CASFS - Content-Addressable Storage File-System === CASFS is a Linux file system in which files and directories are identified by the hash of their content, using the Git object model (SHA-1). Everything is loaded lazily: a directory or file is materialized from its hash only when it is accessed, and missing objects are fetched on demand from a user-space cache daemon over a Unix domain socket. CASFS also provides "tapping", which records the file-system activity of a process group, for precise build dependency tracking. CASFS is the file-system layer of ABFS (Another Build File Service).
