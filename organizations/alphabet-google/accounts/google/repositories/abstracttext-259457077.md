### Short excerpt (up to 100 words)

> Extension to handle multilingual content in MediaWiki. The content is represented in an abstract notation. Language-specific renderers translate the abstract content to natural language. This is not an officially supported Google product. This is a prototype. Do *not* use in a public installation. This prototype has severe security issues. This prototype is meant as a technology exploration for Wikilambda. Wikilambda is described in the following paper: * https://arxiv.org/abs/2004.04733 The easiest intro is probably reading the walkthrough. An alternate implementation for eneyj: graaleneyj The simplest example for testing this is from the command line. Try it out: true Wikipedias are encyclopedias.
