### Short excerpt (up to 100 words)

> a Windows application that allows exploring, as well as interacting with, the Accessibility tree of any Java applications that uses the to expose their accessibility features, for example provides features similar to the Java Ferret and Java Monkey sample applications that were distributed as part of the SDK when it was still distributed as a stand alone download. both set of features in a single application, is more stable and has been tested on recent versions of Windows (7, 8, 8.1 and 10) and offers a more modern and advanced user interface. consumes the same API that Windows screen readers
