## Project overview

Agent Starter Pack was a collection of Google Cloud generative-AI agent templates intended to accelerate project creation and deployment with infrastructure, CI/CD, evaluation and observability scaffolding. Its current README is a migration notice rather than a full project guide.

## Features and capabilities documented by the README

- The README states that Agent Starter Pack has been replaced by Agents CLI.
- Since package version 1.0.0, the agent-starter-pack package installs google-agents-cli and the agent-starter-pack command runs agents-cli.
- Documents renamed command paths for scaffolding, enhancement, upgrade, CI/CD setup and Gemini Enterprise registration.
- Identifies v0.41.3 as the last Agent Starter Pack release.

## Technology stack

Historical Python package and agent templates for Google Cloud; successor package and executable are google-agents-cli / agents-cli. The README points users to GoogleCloudPlatform/agent-starter-pack v0.41.3 for the final legacy release.

## Getting started

For current work, follow the README's successor path and install/use Agents CLI via uvx google-agents-cli or the current Agents CLI documentation. Only use the v0.41.3 source branch when investigating or maintaining an existing legacy Agent Starter Pack project.
