## What it does

Google Core Libraries for Java: a set of reusable Java libraries for common data structures and utility functionality.

## Features documented by the upstream README

- Collection types including multimap and multiset.
- Immutable collections and a graph library.
- Utilities for concurrency, I/O, hashing, primitives and strings.
- Provides a JRE flavour and an Android-compatible flavour.

## Technology stack

Java; JDK 8+ for the JRE flavour; Android flavour; Maven and Gradle dependency management.

README identifies Guava as widely used within Google and by other companies.
