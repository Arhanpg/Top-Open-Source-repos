> Hyperledger Burrow is a permissioned Ethereum smart-contract blockchain node. It executes Ethereum EVM and WASM smart contract code (usually written in Solidity) on a permissioned virtual machine. Burrow is a fully fledged blockchain node and smart contract execution engine -- a distributed database that executes code.
