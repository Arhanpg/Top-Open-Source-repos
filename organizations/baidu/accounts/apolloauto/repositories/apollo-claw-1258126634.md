### Short excerpt (up to 100 words)

> `apollo-claw` 是一组面向 Apollo EDU 与 Apollo 11.0 工作区的 Skills 和本地知识库。环境运维、源码开发、测试和评估能力各自独立，便于在兼容 Skills 目录结构的编码 Agent 中按需使用。 2.0 Skills 包中的专项模块： - `apollo-env`：`env-check`、`install`、`vehicle-restore`、`vehicle-usage`、`gnss-config`、`lidar-config`、`camera-config`。 - `apollo-dev`：`architecture`、`build-test`、`control-dev`、`debug`、`gnss-driver`、`hmi-dev`、`localization-dev`、`new-component`、`perception-dev`、`planning-dev`、`plugin-dev`、`vehicle-sensor`。 - `apollo-test`：`batch`、`build-test`、`debug`、`defect`、`env-check`。 - `apollo-eval`：`realtime_monitor.py` 实时指标监控、`extract_metrics.py` record 指标分析、`grading_system_py` 数据包评分。 这些 Skill 目录包含 `SKILL.md`、脚本和参考资料；兼容此目录结构的编码 Agent 可复用其定义和知识。DSH 的斜杠命令、agent presets 和 Web 插件属于 DSH 集成功能。 客户端插件、预设和可选 LAN 插件通过 npm 分发。 新环境一键安装客户端插件、四个 Skills 和 presets： curl -fsSL https://raw.githubusercontent.com/ApolloAuto/apollo-claw/EDU/ops-expert/install.sh | bash 需要 LAN 访问时添加 `--with-lan`： curl -fsSL https://raw.githubusercontent.com/ApolloAuto/apollo-claw/EDU/ops-expert/install.sh | bash -s -- --with-lan 安装脚本从本仓库分支直接取 `apollo-env`、`apollo-dev`、`apollo-test`、`apollo-eval` 四个目录，复制到 `$DSH_HOME/skills`。如果目标机已有同名 Skill，会先改名为 `<skill>.bak.<时间戳>` 再安装，不直接覆盖。 `apollo-env` 自带车型基线数据，仓库体积主要来自这里；安装时会一并复制到本地 Skill 目录。 本仓库适用于 Apollo EDU 日常运维和 Apollo 11.0 二次开发： - 检查环境、安装依赖、诊断 aem/buildtool/profile 问题。 - 开发或调试 Planning、Control、Perception、Localization、CyberRT 组件及插件。 - 录制和回放实车或仿真数据，盘点 channel 并生成模块信号报告。 - 对已有
