## Setup and usage

- Installation: PaddlePALM support both python2 and python3, linux and windows, CPU and GPU. The preferred way to install PaddlePALM is via pip. Just run following commands in your shell.
- Installation: pip install paddlepalm
- Quick Start: 8 steps to start a typical NLP training task.
- Quick Start: 1. use paddlepalm.reader to create a *reader* for dataset loading and input features generation, then call reader.load_data method to load your training data.
- Quick Start: 2. use paddlepalm.backbone to create a model *backbone* to extract text features (e.g., contextual word embedding, sentence embedding).
- Quick Start: 3. register your *reader* with your *backbone* through reader.register_with method. After this step, your reader is able to yield input features used by backbone.
- Quick Start: 4. use paddlepalm.head to create a task output *head*. This head can provide task loss for training and predicting results for model inference.
- Quick Start: 5. create a task *trainer* with paddlepalm.Trainer, then build forward graph with backbone and task head (created in step 2 and 4) through trainer.build_forward.
