## Baidu AI Cloud note

The Baidu profile mentions “Baidu AI Cloud” as an affiliated organization label, but public GitHub repository searches for plausible exact logins `baidu-ai-cloud` and `Baidu-AI-Cloud` returned no repository results. It is therefore documented as an affiliation label but not added as a standalone GitHub account mapping without a confirmed handle.

## Attribution and scope

- The three secondary accounts use `official-project-linked`, because Baidu's verified GitHub profile identifies them as affiliated organizations.
- This does not claim Baidu legally owns every repository in those accounts or that all projects were authored by Baidu employees.
- Each account remains independently inventoried by its actual GitHub login.
- The primary Baidu inventory and the affiliated account inventories are separate and must all reach complete public pagination before company-level inventory coverage can be marked complete.
