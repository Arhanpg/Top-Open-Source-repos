## Project purpose

An enterprise-grade SDK that lets **ABAP Cloud** (SAP Business AI Platform, ABAP environment / S/4HANA Cloud) applications call **Azure REST APIs** with the same ergonomics you expect from the official Azure SDKs for Java or .NET: a layered HTTP **pipeline**, pluggable **credentials**, typed **exceptions**, and strongly-typed service clients — all written in released, cloud-ready ABAP (ABAP for Cloud Development, language version 5).

## Why this project is used
