## Limitations and caveats

- control-plane subnet and network security group: This subnet is for integrating with Azure Databricks control plane.
- control-plane subnet and network security group: This script creates two rules in network security group for this subnet.
- control-plane subnet and network security group: - Deny all incoming communication
- control-plane subnet and network security group: - Deny all outgoing communication.
- control-plane subnet and network security group: Databricks itself modifies this network security group to additionally add any incoming communication from whole virtual network,
- control-plane subnet and network security group: allows outgoing communication to whole virtual network, outgoing Azure Databricks (port 443), outgoing Azure MySQL DB (port 3306),
- control-plane subnet and network security group: outgoing Azure Storage (port 443) and outgoing Azure Event Hub (port 9093).
- control-plane subnet and network security group: Diagnostic settings of network security group is redirected into Log Analytics.
