### Short excerpt (up to 100 words)

> This repository contains the source code for CLI components for Azure Container Registry. The CLI consists of a new way to interact with Container Registries, the currently supported commands include * Tag: to view all the tags of a repository and individually untag them. * Manifest: to view the manifest of a given repository and delete them if necessary. * Purge: to be able to delete all tags that are older than a certain date and that match a regex specified filter. Before running the ACR-CLI project make sure the following prerequisites are installed. * Go version greater than 1.11
