## Upstream description

Distribution repository holding prebuilt Azure Cosmos DB driver binaries (built from the Cosmos DB Rust driver core for clients) for each supported platform/architecture. These artifacts are consumed by the next-generation Cosmos DB SDKs, which link against the native driver rather than reimplementing it.
