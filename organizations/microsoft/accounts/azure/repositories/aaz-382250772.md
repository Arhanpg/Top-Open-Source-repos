For API version `2026-09-01-preview`, `afd profile create` deliberately supplements the Swagger contract with the optional `--environment-type NonProduction` input at `properties.extendedProperties.environmentType`. Swagger marks the containing `extendedProperties` dictionary read-only, but the RP accepts this specific value when creating an AFD profile in a preview-enabled subscription.
