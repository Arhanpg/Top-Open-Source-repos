### Short excerpt (up to 100 words)

> .NET for Android =============== .NET for Android provides open-source bindings of the Android SDK and tooling for use with .NET managed languages such as C#. This ships as an optional [.NET workload][net-workload] for .NET 6+ that can be updated independently from .NET in order to respond to external dependency updates like new Android platform and tooling. .NET for Android is part of [.NET MAUI][maui-intro], and may also be used independently for native Android development using .NET. .NET for Android is part of .NET MAUI, since it was introduced in May 2022 as part of .NET 6, and is currently supported
