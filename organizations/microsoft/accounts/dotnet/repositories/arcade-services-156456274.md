### Short excerpt (up to 100 words)

> This repo is home of the services that help us construct .NET. Mainly, you can find the **Product Construction Service** (previously *Maestro*) dependency flow system and the Darc CLI tool. The service's main responsibility is opening and managing dependency update pull requests in .NET repositories. It is also responsible for the code flow subscription between product repositories and the VMR. See instructions on how to run the code here. We welcome contributions! Please follow the Code of Conduct. This repo should contain issues that are tied to Maestro and Darc. .NET (including this repo) is licensed under the MIT license.
