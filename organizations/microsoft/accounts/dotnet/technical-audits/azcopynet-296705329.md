## Setup and usage

- Quick start: First, add nuget reference to AzCopy.Client. It provides straight forward API to call into AzCopy v10 cli.
- Quick start: Then add reference to one of the four nuget asset packages based on your OS and platform. The version of these packages are corresponded to the version of azcopy v10 cli it carries with.
- Quick start: If azcopy v10 cli has already installed on your machine, you can also add its full path to $AZCOPYPATH. When running the app, AzCopy.Client will use the azcopy cli pointed by $AZCOPYPATH.
- Quick start: Finally, use AzCopy.Client the same way of using azcopy in cmd!
