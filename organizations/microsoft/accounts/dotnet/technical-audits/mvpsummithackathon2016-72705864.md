## Project purpose

This repository contains the basic sample of an extension to the MSBuild edition of the CLI toolset for .NET Core. The idea of the repo is to provide an easy way to get started with developing extensions to the CLI and the SDK in terms of both MSBuild targets as well as "classic" tools that can be invoked using the dotnet- invocation pattern.

## Why this project is used

Samples for the CLI extensibility hackathon for MVP Summit 2016 in Redmond!
