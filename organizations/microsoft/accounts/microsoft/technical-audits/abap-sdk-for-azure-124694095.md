## Project purpose

ABAP SDK for Azure consists of ABAP objects/classes which simplify SAP and Azure Integration. Now using ABAP code, you can directly send SAP business process data to various Azure services without having to depend on middleware products and solutions. For more information on ABAP SDK for Azure and it’s installation process, Please check document ABAP SDK for Azure – Github
