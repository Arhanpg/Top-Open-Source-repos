### Short excerpt (up to 100 words)

> AAD Connect configuration documenter is a tool to generate documentation of an Azure AD Connect installation. Currently, the documentation is only limited to the Azure AD Connect sync configuration. The goal of this project is to: * To enable quick understanding of the synchronization configuration and "how it happens"! * To build confidence in getting things right when making changes to the default configuration!! * To know what was changed when you applied a new build / configuration of Azure AD Connect or added/updated custom sync rules!!! The current capabilities of the tool include: * Documentation of the complete configuration
