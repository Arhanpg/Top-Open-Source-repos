### Short excerpt (up to 100 words)

> ABAP SDK for Azure consists of ABAP objects/classes which simplify SAP and Azure Integration. Now using ABAP code, you can directly send SAP business process data to various Azure services without having to depend on middleware products and solutions. For more information on ABAP SDK for Azure and it’s installation process, Please check document ABAP SDK for Azure – Github As of now, ABAP SDK supports direct integration with following Azure services, * Event hub * Service bus * Event Grid * Key vault * Active Directory * Blob * Cosmos DB * OMS Log Analytics * Microsoft Graph API
