> **Agent Capability Evaluation Suite (ACES) / Security Agent Benchmarking and Evaluation Research (SABER)** A thin Python library (~5,200 LOC) that lets you define cybersecurity benchmarks using YAML files and run them through inspect_ai's native evaluation engine. No server, no client, no REST API. YAML task configs → saber → inspect_ai Task → inspect eval (data) (library) (native engine) (CLI) 1. **Loads YAML** — task definitions with 3-level config inheritance (global → shared → task) 2. **Renders prompts** — Jinja2 templates → agent instructions, judge prompts 3. **Creates scorers** — atomic, factory-created scorers with unified `ScoringContext` 4. **Provides tools** — `@tool`-decorated
