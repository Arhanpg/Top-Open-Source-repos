### Short excerpt (up to 100 words)

> A thin Python library for benchmarking AI security agents using YAML-driven task definitions and the inspect_ai evaluation framework. No server, no client — just `inspect eval`. YAML task configs → saber → inspect_ai Task → inspect eval (data) (library) (native engine) (CLI) SABER loads YAML task definitions, renders Jinja2 prompts, and produces native inspect_ai `Task` objects.
