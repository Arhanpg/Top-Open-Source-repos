### Short excerpt (up to 100 words)

> The typical system layout for 3D Telemedicine is to have one machine running Fusion, and a separate machine running Render and Viewer. The pods all run their own copy of the K4AToFusion code and should be networked into the same network as Fusion. Control panel can be run on the Fusion PC, the Render PC, or a separate PC or tablet. - Windows 11 - CUDA 11.7 - Nvidia GPU 2080Ti or larger - 10 Gigabit ethernet adapter - OpenCV 4.5.4 We use OpenCV with CUDA libraries.
