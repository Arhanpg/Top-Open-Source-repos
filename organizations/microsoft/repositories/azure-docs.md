## Project overview

The source repository for open-source Microsoft Azure documentation published through Microsoft Learn. The README invites contributors to improve Azure documentation and directs them to the Microsoft contributor guide for authoring tools and pull-request procedures.

## Features and capabilities documented by the README

- Hosts the Markdown documentation source for Microsoft Azure content published on Microsoft Learn.
- Directs contributors to the Azure documentation contributor guide for content changes, issue reporting and pull-request processing.
- Supports browser-based edits for small corrections and pull requests for larger documentation changes.
- Separates product feedback from documentation feedback through the feedback control at the bottom of published articles.
- References distinct LICENSE, LICENSE-CODE and third-party notices, so content and code licensing must be read separately.

## Technology stack
