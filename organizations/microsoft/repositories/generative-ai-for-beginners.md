## Project overview

A 21-lesson learning curriculum from Microsoft Cloud Advocates that teaches the fundamentals of building generative-AI applications. It combines written lessons, short videos, hands-on code examples and links to further learning.

## Features and capabilities

- 21 lessons progress from generative-AI and LLM foundations through model selection, responsible AI, prompt engineering and application building.
- Each lesson includes written material, a short video introduction and runnable code samples.
- The README lists Python and TypeScript examples and documents Azure OpenAI, Microsoft Foundry Models, OpenAI API and Foundry Local paths.
- Foundry Local is presented as an option for running models offline on a learner's own device.
- The course has a setup lesson, learner support/community links and a keep-learning section.
- The repository supports more than 50 language translations maintained through Co-op Translator.

## Technology stack

This is educational material and sample code, not a single deployable application. README-supported technologies include Python, TypeScript, Azure OpenAI Service, Microsoft Foundry Models, the OpenAI API and Foundry Local.

## Getting started

Start with the Course Setup lesson, fork the repository and choose one of the supported model access paths. The README says GitHub Models was retired at the end of July 2026 and directs learners to Microsoft Foundry Models instead; follow the current setup instructions for credentials and environment configuration.

## Lifecycle, licensing and operational notes

Some lessons require cloud accounts or API access; Foundry Local is the documented offline alternative. The provider list and lesson requirements can change between course versions.
