## Project overview

This repository is the open-source Code - OSS codebase used to develop Visual Studio Code with the community. The branded Visual Studio Code distribution is built from Code - OSS and adds Microsoft-specific customizations under a separate Microsoft product licence.

## Features and capabilities

- Core edit-build-debug workflow with code editing, navigation, code understanding and lightweight debugging.
- Extensible editor model, including bundled extensions for language grammars, snippets and language-specific capabilities.
- Roadmap, monthly iteration plans and endgame plans are maintained alongside the source and issue tracker.
- Development container support for VS Code Dev Containers and GitHub Codespaces.
- Related projects such as debug adapters and documentation are maintained in separate repositories and linked from the wiki.

## Technology stack

The README documents Code - OSS as an editor product source, a rich extension model and a development-container workflow. The overview does not provide a full implementation-language or framework inventory; that requires source and manifest inspection.

## Getting started

Use the contribution wiki for building, running, debugging, testing and coding guidelines. The README recommends a development container; a full build needs at least 4 CPU cores and 6 GB RAM, with 8 GB recommended.

## Lifecycle, licensing and operational notes

The source in this repository is MIT-licensed. The branded Visual Studio Code distribution adds Microsoft-specific customizations and is released under Microsoft's separate product licence. The README describes monthly stable releases and an Insiders channel.
