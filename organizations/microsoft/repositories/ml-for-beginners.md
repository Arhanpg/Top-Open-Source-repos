## Project overview

A 12-week, 26-lesson curriculum from Microsoft Cloud Advocates that introduces classic machine learning using primarily scikit-learn. The README says it focuses on classic machine learning rather than deep learning, which is covered by a separate AI for Beginners curriculum.

## Features and capabilities documented by the README

- 26 lessons organised across a 12-week project-based curriculum.
- Uses datasets and case studies from cultures and regions around the world.
- Each lesson includes pre- and post-lesson quizzes, written instructions, a solution, an assignment and additional learning material.
- The README emphasises learning by building, and links companion Data Science for Beginners and AI for Beginners courses.
- The repository supports 50+ translations maintained through Co-op Translator.
- Lesson resources include offline access, PDFs, quizzes and walkthrough material.

## Technology stack

Python; scikit-learn is named as the primary machine-learning library. This is an educational curriculum, not a single deployable product or unified ML framework.

## Getting started

Fork and clone the repository, then follow the Getting Started and environment setup instructions. The README notes that translated content substantially increases repository size and recommends sparse checkout to omit translations when they are not required.

## Lifecycle, compatibility and operational notes

The course intentionally focuses on classic machine learning and avoids deep learning. Use the linked AI for Beginners material for deep-learning topics. Lesson examples and setup instructions may evolve over time; use the specific lesson README for requirements.
