## Project overview

A course teaching learners how to design and build AI agents. Its lesson sequence covers agent foundations, frameworks and design patterns, tools, agentic RAG, trustworthiness, planning, multi-agent systems, production deployment, protocols, context engineering and memory.

## Features and capabilities

- Each lesson includes written material, a short video and Python code samples.
- The README lists lessons on agent introduction, frameworks, design patterns, tool use, agentic RAG, trustworthy agents, planning, multi-agent systems, metacognition, production, MCP/A2A/NLWeb protocols, context engineering and memory.
- Documented examples use Microsoft Agent Framework with Microsoft Foundry Agent Service V2.
- Some examples support alternative OpenAI-compatible providers such as MiniMax.
- The course links setup instructions, extra learning resources and a Microsoft Foundry Discord community.
- The repository includes translated versions of the course.

## Technology stack

Python examples; Microsoft Agent Framework; Microsoft Foundry Agent Service V2; optional OpenAI-compatible model-provider paths described by the README. This repository is a course and sample-code collection, not a standalone agent runtime.

## Getting started

Start with the course setup guide and configure the required Azure/Microsoft Foundry account and service. The README says each lesson's Python samples use Microsoft Agent Framework with Microsoft Foundry; the setup guide explains providers and credentials.

## Lifecycle, licensing and operational notes

The README recommends taking Generative AI for Beginners first if new to generative-AI models. The lesson list and service integrations may change, so check the current course setup before running samples.
