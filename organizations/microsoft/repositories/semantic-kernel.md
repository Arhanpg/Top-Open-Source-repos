## What it does

A model-agnostic SDK for building, orchestrating and deploying AI agents and multi-agent systems. The README identifies Microsoft Agent Framework as its enterprise-ready successor.

## Features documented by the upstream README

- Connects to multiple model providers including OpenAI, Azure OpenAI and Hugging Face.
- Builds modular agents with tools/plugins, memory and planning.
- Orchestrates collaborating specialist agents.
- Supports vector databases, text/vision/audio inputs and local deployment options such as Ollama, LM Studio and ONNX.
- Includes a structured process framework for business workflows.

## Technology stack

Python 3.11–3.14; .NET 10+; Java JDK 17+ (as specified in README system requirements); integrations include OpenAI-compatible services, vector databases and local model runners.

## Notes and limitations

README prominently says Semantic Kernel is now Microsoft Agent Framework and links a migration guide. Preserve this lifecycle context when evaluating adoption.
