## What it does

A data pipeline and transformation suite that extracts meaningful structured data from unstructured text using LLMs; it explores graph-based context for question answering over private data.

## Features documented by the upstream README

- Transforms unstructured text into structured data using LLMs.
- Uses knowledge-graph memory structures to form targeted context for question answering.
- Provides a command-line quickstart, documentation and prompt-tuning guidance.
- Includes responsible-AI and project-limitation documentation.

## Technology stack

Python package / PyPI (`graphrag`); LLM-based extraction and knowledge-graph concepts.
