## What it does

A web automation and testing framework that drives Chromium, Firefox and WebKit through one API.

## Features documented by the upstream README

- Playwright Test end-to-end test runner.
- Browser isolation through fresh browser contexts for tests.
- Auto-waiting, web-first assertions and resilient locators.
- Trace capture including screenshots, videos, DOM snapshots, network requests and console messages.
- Parallel test execution; ecosystem also includes CLI, MCP server, library and VS Code extension.

## Technology stack

Node.js / npm package ecosystem; README examples and API usage in TypeScript; Chromium, Firefox and WebKit browser engines.

## Notes and limitations

The README describes multiple ways to use Playwright: Test, CLI, MCP, Library and VS Code Extension.
