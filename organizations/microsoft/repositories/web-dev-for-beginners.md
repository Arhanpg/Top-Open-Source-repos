## Project overview

A 12-week curriculum containing 24 lessons for learning the fundamentals of web development. The README presents it as a project-based course created by Microsoft Cloud Advocates, covering HTML, CSS and JavaScript.

## Features and capabilities

- 24 lessons organised into a 12-week course.
- Hands-on projects include a terrarium, browser extension and space game.
- Lessons combine quizzes, discussions and practical assignments.
- The README explains the project's project-based pedagogy and provides environment setup guidance.
- The repository supports 50+ translated versions through an automated GitHub Action and Co-op Translator.
- Related courses are linked for generative AI, agents, Azure, Edge, MCP and core learning.

## Technology stack

HTML, CSS and JavaScript are named as the core teaching technologies. This repository is a curriculum with lesson pages, project assets, quizzes and translations, not a single web application framework or runtime.

## Getting started

Fork and clone the repository, then follow the environment setup instructions. For a smaller local clone, the README recommends sparse checkout excluding the translations directory because translated content increases download size.

## Lifecycle, licensing and operational notes

This is beginner learning material rather than a deployable web product. Translation folders are substantial and can be omitted from a local learning copy when not needed.
