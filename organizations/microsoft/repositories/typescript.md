## What it does

A language for application-scale JavaScript that adds optional types and compiles to readable, standards-based JavaScript.

## Features documented by the upstream README

- Optional type system for JavaScript applications.
- Tooling support for large-scale JavaScript development.
- Targets browsers, hosts and operating systems through JavaScript output.
- Provides a playground, handbook, roadmap and contribution workflow.

## Technology stack

TypeScript / JavaScript; npm installation (`typescript` package).

## Notes and limitations

The README describes TypeScript as a language and compiler/tooling layer, rather than a standalone application.
