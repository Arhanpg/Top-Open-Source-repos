## Attribution and scope

- `official-project-linked` means the company-controlled documentation page links to repositories in the account. It is not a blanket legal-ownership or authorship claim for all repositories.
- Repository ownership remains with the account shown in the canonical GitHub URL.
- Microsoft states that it has over 100 GitHub organizations dedicated to open-source activities. The three additional accounts in this register are therefore a partial evidence-backed expansion, not a complete enumeration of Microsoft organizations.
- Other Microsoft-associated accounts must be discovered from company-controlled sources and recorded separately when the specific login is supported by a source.

## Inventory status

The collector will enumerate the primary account and these three documentation-linked accounts independently. A company-wide Microsoft inventory must remain open until the wider official organization set is discovered and each account is paginated.
